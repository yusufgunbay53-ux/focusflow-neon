# FocusFlow

AI destekli gorev ve odaklanma asistani. Karanlik neon arayuz, surukle-birak Kanban, 25/5 Pomodoro, tarayicida uretilen yagmur / lo-fi ortam sesi ve gunluk verilere gore mock performans kocu.

## Calistirma

```bash
npm install
npm run dev
```

Uygulama http://localhost:3000 adresinde acilir.

Veri modelleri `lib/models.js` icinde. Supabase veya Firebase icin `lib/storage.js` load/save fonksiyonlarini ayni imzayla degistirin.
